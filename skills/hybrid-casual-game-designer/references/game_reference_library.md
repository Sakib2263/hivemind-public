## JAM / UNBLOCKING FAMILY

### Color Block Jam (Rollic/Zynga)
```
Mechanic:        Directional block slide to shredder/exit points
Win condition:   All blocks removed from grid
Fail condition:  No available moves (deterministic — no tray)
Tray system:     None — direct exit mechanic
Key innovation:  "Lego-like" toyetic visual, physics-snap movement
CPI hook:        Lego-familiar blocks + satisfying puzzle clear
Revenue:         $250K+/day at peak — current benchmark
Ads start:       Level 14 (interstitial after every level post-14)
Publisher:       Rollic (Zynga)
Sara fit:        8/10 — clean, colorful, satisfying
Mechanic note:   Deterministic levels (same each restart) = key retention driver
```

### Block Jam 3D (Voodoo)
```
Mechanic:        3D spatial unblocking — same as Color Block Jam but 3D view
Win condition:   All blocks removed
Fail condition:  No available moves
Key innovation:  3D perspective adds spatial reasoning depth
CPI hook:        3D blocks look more toyetic
Publisher:       Voodoo
```

### Screw Jam (Rollic)
```
Mechanic:        Unscrew bolts in correct order to free boards
Win condition:   All boards freed
Fail condition:  No available moves (order matters critically)
Key innovation:  Order-of-operations creates deep planning
CPI hook:        "Can you figure out the order?" challenge
Publisher:       Rollic
Sara fit:        7/10 — satisfying but slightly abstract theme
```

### Car Parking Jam
```
Mechanic:        Slide cars out of parking lot without collision
Win condition:   Target car exits
Fail condition:  No available moves
Key innovation:  Real-world spatial reasoning (parking = universal)
CPI hook:        "Get this car out" — universal frustration
```

## SORT / STACK FAMILY

### Hexa Sort
```
Mechanic:        Tap tile stacks to sort by color into hexagonal columns
Win condition:   All stacks sorted by single color
Fail condition:  No available column space (stack overflow)
Tray system:     Columns act as buffer (5-6 tiles per column)
Key innovation:  Hexagonal grid creates non-obvious spatial depth
Revenue:         $300M+/year — D30 retention king
Sara fit:        9/10 — color sorting + satisfying column completion
D30 driver:      Column completion animation is exceptionally satisfying
```

### Water Sort Puzzle (IEC Global)
```
Mechanic:        Pour colored liquids between tubes to sort by color
Win condition:   All tubes contain single-color liquid
Fail condition:  No available pours (all tubes full of wrong colors)
Key innovation:  Liquid animation = strongest tactile feel in category
Sara fit:        8/10 — satisfying liquid pour + clean color sorting
```

### Goods Sort (YL Games)
```
Mechanic:        Tap items from shelf grid, sort to matching shelf categories
Win condition:   All items sorted to correct shelves
Fail condition:  Tray slot full
Tray system:     Holding tray (5 slots) between source and destination
Key innovation:  Destination sorting adds routing decision vs. pure match
Sara fit:        9/10 — home organization fantasy is perfect
Note:            Closest reference to "Shelf Rush" concept
```

### Triple Tile (Tripledot Studios)
```
Mechanic:        Tap tiles to collect matching sets of 3
Win condition:   All tiles cleared via 3-of-a-kind sets
Fail condition:  Tray slot full (7-slot collection bar)
Tray system:     7-slot collection bar with auto-sort by type
Key innovation:  Mahjong-style set collection + visual pile
Sara fit:        8/10 — collection + matching
D30 driver:      Set collection creates strong "one more match" loop
Note:            Closest reference to "Gem Depot" concept
```

### Bolt Sort
```
Mechanic:        Move colored bolts onto matching posts (stack sort)
Win condition:   All posts contain single-color bolts
Fail condition:  No available post space
Key innovation:  Stacking posts create vertical spatial planning
Note:            Core base for Hauler Sort Puzzle mashup
```

### Twisted Tangle (Rollic)
```
Mechanic:        Untangle colored string/rope by moving endpoints
Win condition:   All strings untangled
Fail condition:  No available moves
Key innovation:  Physics-like tangling creates satisfying unwind moment
Sara fit:        9/10 — untangling = order-from-chaos fantasy
D30 driver:      Progressive reveal as tangle loosens
Note:            Reference for "Knot Sort" core visual fantasy
```

## CONVEYOR / ROUTING FAMILY

### Collect Em All! (Voodoo)
```
Mechanic:        Draw paths to collect falling/moving items
Win condition:   Collect quota of each item type
Fail condition:  Items escape uncollected
Key innovation:  Path-drawing creates spatial routing challenge
CPI hook:        Colorful items falling = high visual engagement
Publisher:       Voodoo — their current flagship recommendation
```

### Foodie Sizzle (referenced in Supersonic playbook)
```
Mechanic:        Match food items to correct cooking stations
Win condition:   Complete all orders
Fail condition:  Tray slot full / station overflow
Theme:           Restaurant kitchen — confirmed high Sara fit by Supersonic
Note:            Direct theme reference for "Kitchen Rush Conveyor"
```

## MARKET PATTERN OBSERVATIONS

### What Supersonic is currently buying (from playbook analysis)
- Deterministic puzzle mechanics (same each restart = fair)
- 4-element screen layout compliance
- Toyetic / tactile visual hooks
- Sara-demographic themes: Food, Jewelry, Toys, Yarn
- D30 retention > 20% trajectory
- Clean IAA monetization with natural RV placement

### What Voodoo is currently buying (from strategy documents)
- "Player fantasy" over mechanic novelty
- Silent tutorial (zero text in levels 1-10)
- Visual hook that stands out in 3-second scroll
- App size < 100MB (non-negotiable)
- 20% D30 retention potential ("DREAM BIG" test)
- Clean, low-friction first experience

### Saturated Mechanic Combinations (avoid)
- Match-3 + decoration meta (Royal Match clones — oversaturated)
- Directional block slides + shredder exit (Color Block Jam direct clones)
- Water pour sorting (Water Sort Puzzle saturated)
- Simple parking jam (Car Parking Jam oversaturated)

### Whitespace Opportunities (as of 2025-2026)
- Jam mechanic + destination routing (not shredder) + Sara theme
- Set collection + jam hybrid (Gem Depot direction)
- Yarn/fiber + sort mechanic (Knot Sort direction)
- Conveyor belt routing + station management (Kitchen Rush direction)
- Block jam + picture completion (Block Picture direction)
