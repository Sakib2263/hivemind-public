# Ideation Checklist & Validation Gates
## Reference: Supersonic + Voodoo Playbook Synthesis

---

## THE DREAM BIG TEST (Voodoo Standard)
Before any concept moves forward, it must answer YES to all three:
- [ ] Can this idea exceed 20% D30 retention after 1 year?
- [ ] Is there a unique core twist that makes it different from current top 20?
- [ ] Can we describe 3 distinct CPI ad concepts for this right now?

If any answer is NO, the concept is not ready. Keep ideating.

---

## PHASE 1 — CONCEPT GENERATION CHECKLIST

### Market Fit
- [ ] Is this mechanic family (Jam/Sort/Conveyor/Match) currently trending or stable?
- [ ] Does this avoid the top 3 most-saturated mechanic combinations right now?
- [ ] Is there a clear gap in the market this fills (theme gap, mechanic gap, audience gap)?
- [ ] Can you name 2-3 reference games that prove the base mechanic works?
- [ ] Can you name what makes THIS version different from those references?

### Sara Persona Fit
- [ ] Primary audience: 35-44 female, US/Western Europe
- [ ] Session context: commute, lunch break, before sleep (5-12 min sessions)
- [ ] Theme check — does it rank on Sara's preference list?
  - TIER 1: Home organization, Food/Kitchen, Jewelry/Accessories
  - TIER 2: Yarn/Crafts, Garden, Toys/Puzzles, Candies
  - TIER 3: Anything else (needs extra justification)
- [ ] Sara CANNOT encounter: Sci-fi, combat, dark themes, speed-based pressure
- [ ] Sara MUST encounter: Tactile snapping, color clarity, satisfying chain reactions, warm palettes
- [ ] Emotional need served: Stress relief through order-making (chaos -> neat)

### The 2+1 Mashup Validation
```
BASE MECHANIC:         [Name] — proven by [Reference Game] with [KPI evidence]
TENSION SYSTEM:        [Name] — creates pressure via [specific mechanism]
THEME SKIN:            [Name] — Sara fit score [1-10] — no Sara red flags?

Mashup coherence check:
  [ ] Does the tension system ENHANCE the base mechanic (not fight it)?
  [ ] Does the theme skin amplify the visual fantasy without adding complexity?
  [ ] Can a player understand all three elements within 10 seconds of play?
```

### CPI Readiness
- [ ] Can you describe a 15-second ad for this game right now?
- [ ] Does the ad open with a visual hook in the first 3 seconds?
- [ ] Is there a clear "fail bait" version of the ad (player makes a mistake, viewer wants to fix it)?
- [ ] Is there a "satisfying loop" version (viewer sees the relief moment and wants to feel it)?
- [ ] Would this ad work as a silent video? (Voodoo standard: assume no audio)

## PHASE 2 — CONCEPT VALIDATION GATES

All five gates must pass before a concept enters Week 1 production.

### Gate 1: Core Loop Clarity
Present the concept to someone unfamiliar with it. Ask: "What does the player do?"
- PASS: They describe the core action correctly within 30 seconds
- FAIL: They ask a clarifying question → simplify the concept

### Gate 2: The Napkin Test
Draw the core loop on a napkin (5 elements: input state, player action, buffer, relief, fail).
- PASS: Loop fits on one side of a napkin
- FAIL: You need more space → concept is too complex

### Gate 3: The Relief Moment Test
Describe the single most satisfying visual moment in the game in 10 words.
- PASS: You can describe it in 10 words, and it sounds genuinely satisfying
- FAIL: Description requires more than 10 words, or sounds abstract
Example PASS: "Three gems merge into a glowing jewel with particle burst"
Example FAIL: "The player strategically routes items to achieve an optimal configuration"

### Gate 4: The Fail State Test
Ask: Is the fail state visible coming? Can Sara anticipate it?
- PASS: Tray fills visibly (3/5 → 4/5 → 5/5), player has time to react
- FAIL: Fail arrives suddenly with no warning → add warning state

### Gate 5: The 4-Week Feasibility Test
Can a team of 2-3 developers build a 20-level prototype in 4 weeks?
- Count of unique mechanics required: must be 1 (not 2+) for first prototype
- Number of unique art assets required: must be <20 for V1
- Any 3D or physics simulation required? If yes, add 1 week to estimate
- PASS: 4-week timeline feels achievable with current team
- FAIL: Scope needs cutting; identify which features move to V2

## PHASE 3 — CONCEPT SCORING RUBRIC

Score each concept 1-10 on each axis, then sum for total (max 50).

| Axis | 1-3 (Weak) | 4-6 (Acceptable) | 7-9 (Strong) | 10 (Exceptional) |
|---|---|---|---|---|
| **Sara Fit** | Sci-fi/combat theme, no tactile hook | Neutral theme, limited tactile | Strong theme, clear tactile, stress-relief obvious | Perfect theme + tactile + emotional resonance |
| **Novelty** | Direct clone of existing top-5 game | Incremental improvement on existing | Clear new mechanic combination not in top 20 | First-of-kind mechanic never seen in charts |
| **Feasibility** | Requires 3+ months minimum | 6-8 week prototype possible | 4-week prototype achievable | 2-week first playable achievable |
| **Ad Potential** | Cannot describe a 15-sec ad | Ad exists but hook is weak | Strong hook, 3+ creative angles possible | Hook is so strong the ad practically writes itself |
| **D30 Potential** | Single mechanic, no depth | Some depth but no escalation path | Clear mechanic escalation + blocker roadmap | Dual-relief moments + meta layer path evident |

**Recommended thresholds:**
- Score 40-50: Greenlight immediately
- Score 30-39: Requires one more iteration before greenlighting
- Score 20-29: Concept needs major rework
- Score below 20: Kill and replace

## KNOWN HIGH-RISK PATTERNS (from Supersonic + Voodoo playbooks)

These patterns have historically caused prototype failure. Flag if any are present:

1. **Tutorial creep** — More than 3 steps of onboarding in levels 1-3
2. **Mechanic bloat** — More than 1 new mechanic in the first 10 levels
3. **Invisible fail** — Player can't see the fail coming until it's already happened
4. **Speed dependency** — Any mechanic that requires fast reactions (wrong audience)
5. **Text dependency** — Any mechanic that requires reading to understand
6. **Unfair fail** — Player can lose due to grid configuration, not their own decisions
7. **Weak first 10 seconds** — Opening board doesn't immediately suggest what to do
8. **Dark or complex theme** — Themes that don't serve the 35-44 female demographic
9. **Physics randomness** — Random elements affecting win/fail outcome
10. **Missing relief moment** — Game has challenge but no clear "aaah" satisfaction payoff
