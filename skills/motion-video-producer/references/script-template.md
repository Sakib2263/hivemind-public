# Video Script Template

Use this structure for every script MD. Header: title plus version/date/status only (no "Prepared by", "Owner", etc.).

```
# <Product> — Motion Animated Explainer Video: Script & Flow

Version 1.0 | <date> | Draft

## 1. Video at a Glance
| Item | Detail |
|---|---|
| Format | 2D motion graphics explainer, with UI screen animations |
| Length | Master cut m:ss (cutdowns at 60s, 30s, 15s) |
| Audience | <who decides / who watches> |
| Goal | <the one action viewers should take> |
| Core message | <one sentence> |
| Tagline | <end-card line> |
| Voiceover | <language, voice style; local-language version?> |
| Tone | <3-4 words> |

## 2. Story Flow (N Acts)
1. The Problem — <pain in one line>
2. Meet <Product> — <what it is in one line>
3. How It Works — <mechanism>
4. ... proof / use cases / benefits / why us
N. How to Start + Call to Action

## 3. Scene-by-Scene Script
### ACT 1 — <name> (0:00 – 0:20)
**Scene 1 (0:00 – 0:08)**
- Visual: <what is on screen>
- Motion: <how it moves>
- On-screen text: "<exact words>"
- VO: "<exact spoken line>"

## 4. Full Voiceover (Clean Read)
<all VO lines as paragraphs> — Word count: approx. N words (≈150 words per minute)

## 5. Cutdown Versions
| Cut | Length | Use | Scenes |

## 6. Visual & Production Guide
Style · Colors (hex) · Fonts · Music & Sound · Assets needed from team · Delivery formats
```

## Writing rules that worked

- Open on the viewer's problem, never on the product. Reveal the product only after the pain lands (about 10–15% in).
- One idea per scene. If a VO line has two ideas, split the scene.
- VO pace: 140–160 words per minute for explainers. 3:00 ≈ 400–450 words. Short cuts get their own rewritten VO, not trimmed lines.
- Plain spoken English, short sentences, no jargon. Read every line out loud in your head.
- Every abstract claim gets a concrete visual (a phone screen, a leaderboard, a shop, a chart).
- Mark invented example content (brand names, numbers) as illustrative and tell the user.
- End card always carries: product logo, tagline, one CTA, real contact details (pull them from project files, never invent).

## Cutdown recipes

| Cut | Structure | Notes |
|---|---|---|
| 60s | short intro → problem → reveal → fast mechanism (≈4s per step) → proof/flywheel → one-line use cases → benefits → end card | skip deep dives |
| 30s | problem → reveal → one proof → 3 benefits → end card | no intro sting; hook first |
| 15s | problem line → reveal → end card | bumper; tagline is the whole message |
