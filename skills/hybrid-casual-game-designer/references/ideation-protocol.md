## THE 2+1 MASHUP FORMULA

Every concept must be built from this structure:
```
[PROVEN BASE MECHANIC] + [COMPLEMENTARY TENSION SYSTEM] + [THEMATIC SKIN]
```

The Base Mechanic must already exist in the top 50. The Tension System must add a second decision layer that the base game doesn't have. The Thematic Skin must score ≥7 on the Sara Filter.

**Validated Mashup Examples (from project knowledge base):**
- Car Match grid + Bolt Sort haulers + Parking lot → *Hauler Sort Puzzle*
- Color Block Jam blocks + Wordle board + Office skin → *Word Block Jam*
- Bolt Sort posts + Yarn theme + Knitting skin → *Knot Sort*
- Color Block Jam blocks + Triple Tile set-collection + Jewelry skin → *Gem Depot*
- Goods Sort routing + Conveyor timing + Kitchen skin → *Kitchen Rush Conveyor*

**Whitespace Combinations (Not yet dominated):**
- Screw Jam unscrew + Hexa Sort stacking + Spa/Boutique skin
- Triple Tile 3-match + Conveyor delivery timing + Bakery skin
- Block Jam spatial + Liquid pour sort + Cozy home skin
- Water Sort + Category matching (not just color) + Herbalist/Potion skin
- Path drawing + Destination routing + Garden/Greenhouse skin

## CONCEPT GENERATION CHECKLIST

When asked to generate concepts, always produce ≥ 5. Never fewer. Score each immediately.

## VOODOO IDEATION TEMPLATE (From Voodoo Prototyping Guideline)

This is the exact template Voodoo uses in their ideation process. Use it alongside the full template above.

```
PICK THE GAMEPLAY:
  Twist: [What is unique about this vs. existing games?]
  How to play: [One sentence, zero jargon]
  How to win: [One sentence]
  How to lose: [One sentence]
  Have players seen & felt this before? [YES/PARTIALLY/NO]
  Will players pay to keep playing when they lose? [YES/MAYBE/NO]
  Would a 35-year-old US woman play my game? [YES/MAYBE/NO]
```

## POST-GENERATION RANKING PROTOCOL

After listing all concepts:

1. Sort by combined score (Sara Fit × D30 Potential weighted 40%, Ad Potential 30%, Novelty + Feasibility 30%)
2. Write a ranked recommendation table:

```
| Rank | Concept | Combined Score | Submit First? | Why |
|---|---|---|---|---|
| 1 | [Name] | [X/50] | YES | [one sentence] |
| 2 | [Name] | [X/50] | Backup | [one sentence] |
...
```

3. Write a 2-paragraph rationale for the #1 recommendation covering: why it beats #2, what the core retention driver is, and what must go right in Week 2 for it to succeed.

## IDEATION ANTI-PATTERNS (Never Do These)

- Never propose a mechanic without naming a game reference it's derived from
- Never generate a concept without a CPI ad brief
- Never score Sara Fit > 7 for any concept with: timers as core mechanic, combat, sci-fi skin, randomized outcomes, complex multi-step tutorial requirement
- Never generate fewer than 5 concepts when asked for concepts
- Never describe a mechanic vaguely — always use exact slot counts, grid sizes, and action verbs
- Never skip the Risk Flag — overconfident pitches don't get greenlit
- Never recommend a concept with Feasibility < 6 as the primary submission without flagging the risk explicitly
